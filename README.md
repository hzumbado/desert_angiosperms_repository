Overview

This GitHub repository contains the data, and code used to generate the results presented in the associated manuscript. The archive is intended to ensure long-term preservation, transparency, and reproducibility of all analyses.

All analyses were conducted in R and include species distribution modeling, spatial analyses, phylogenetic regionalization, and projections of future range shifts for angiosperm species in desert ecosystems of southern California.

Contents of This Archive

This Zenodo deposit includes:

Raw datasets used in the analyses

Processed datasets derived from raw inputs

Metadata files describing variables, units, and data sources

Supplementary materials required to reproduce the analyses

File names and formats are documented within the metadata files.

Computational Environment

All analyses were conducted using:

R version: 4.5.2

**Key R Packages**

The following packages were central to the analyses:

ENMeval — evaluation and tuning of species distribution models

ecospat — niche dynamics and spatial ecology analyses

phyloregion — phylogenetic regionalization and diversity metrics

Hmsc — Hierarchical Modelling of Species Communities

tidyverse — data processing, visualization, and figure generation

terra — spatial raster processing

sf — vector-based spatial analysis



Exact package versions can be retrieved by running sessionInfo() in R.

Reproducibility

To reproduce the analyses:

Download the Zenodo archive and extract all files.

Clone or download this GitHub repository linked above.

Ensure R (version 4.5.2) and required packages are installed.

Update file paths in the R scripts if necessary.

Run scripts sequentially following their numeric prefixes.
